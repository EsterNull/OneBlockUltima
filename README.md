# OneBlock Ultima

## Requirements

- **JDK 8** (required — ForgeGradle 1.2 / Gradle 4.4.1 do not run on newer JDKs, e.g. JDK 21 fails with `Unable to get mutable Windows environment variable map`).
- Minecraft Forge **1.7.10-10.13.4.1614-1.7.10** (resolved automatically by the build).
- Gradle **4.4.1** (via the wrapper — do not use a newer Gradle, ForgeGradle 1.2 is incompatible with it).
- Tested on Windows, but the build is cross-platform.

Set `JAVA_HOME` to your JDK 8 before running any Gradle task:

```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk-1.8"
$env:Path = "C:\Program Files\Java\jdk-1.8\bin;$env:Path"
```

## Build

First-time setup (downloads ForgeGradle, Minecraft and decompiles the workspace; requires network):

```powershell
gradlew setupDecompWorkspace
```

Then build (reobfuscation runs automatically after `jar`):

```powershell
gradlew build
```

Produces the reobfuscated release jar in `build/libs/OneBlockUltima-forge-1.7.10-<version>.jar`. Drop it into the `mods/` folder of a 1.7.10 Forge instance.

Other useful tasks:

| Task | Purpose |
| --- | --- |
| `gradlew setupDecompWorkspace` | One-time workspace setup (decompiles Minecraft, required for `runClient`). |
| `gradlew setupCIWorkspace` | Lightweight setup for building/testing only (no client sources). |
| `gradlew runClient` | Launch the Minecraft client with the mod (username `DevPlayer`). |
| `gradlew runServer` | Launch a dedicated server with the mod. |
| `gradlew test` | Run unit tests (JUnit 4, pure JVM, no client needed). |
| `gradlew idea` | Generate IntelliJ IDEA project files (`OneBlockUltima.ipr` / `.iml`). |
| `gradlew eclipse` | Generate Eclipse project files. |
| `gradlew clean` | Clean `build/`. |

## IDE setup (IntelliJ IDEA)

ForgeGradle 1.2 is tied to Gradle 4.4.1, which modern IntelliJ IDEA (2024.x) refuses to import (`Unsupported Gradle version` — the Gradle sync fails and IntelliJ ends up with no classpath, showing hundreds of false errors). **Do not import the project as a Gradle project.**

Instead:

1. Run `gradlew setupDecompWorkspace`.
2. Run `gradlew idea` — generates `OneBlockUltima.ipr` / `OneBlockUltima.iml` with the full Minecraft/Forge classpath baked in.
3. In IntelliJ: `File → Open` → select `OneBlockUltima.ipr`.
4. Make sure the Project SDK is **JDK 8**.
5. Build and run from the terminal via `gradlew` (the Gradle tool window will not work).
6. After changing dependencies in `build.gradle`, re-run `gradlew idea` to refresh the module.

The [Minecraft Development](https://plugins.jetbrains.com/plugin/8327-minecraft-development) plugin auto-detects ForgeGradle 1.2 and is recommended.

> **Note:** the `.iml` generated by `gradlew idea` includes a legacy *Minecraft facet* (`McpModuleSettings srgType=SRG`). IntelliJ 2024.x misinterprets it for ForgeGradle 1.2 and produces false errors (e.g. *Incompatible types: Found `NBTTagDouble`, required `NBTBase`*, or *Cannot resolve symbol* for MCP names), even though `gradlew build` succeeds. If you see such errors, delete the `<component name="FacetManager">` and `<component name="McpModuleSettings">` blocks from `OneBlockUltima.iml` and reopen the project — the module then resolves against the MCP-named `forgeBin` jar exactly like javac.

For Eclipse: run `gradlew setupDecompWorkspace` and `gradlew eclipse`.

## Versioning & config

- Version lives in `build.gradle`, also injected into `mcmod.info` during `processResources`.
- Runtime config is written to the Forge config dir:
  - `config/oneblockultima/oneblockultima_mod_settings.json` — mod settings.
  - `config/oneblockultima/blocksets.json` — block sets (created from bundled defaults on first launch).
  - `config/oneblockultima/block_prices.json` — price table.

## Logging / Debug mode

All mod logging goes through `OneBlockUltima.getLogger()` (a `java.lang.reflect.Proxy` wrapper). When the **Debug mode** toggle in Settings → Misc is off, every call is suppressed; when on, calls are forwarded to the mod logger. Don't use `System.out.println` for mod logs.

## Tests

Unit tests run in a pure JVM via `gradlew test` (no Minecraft client is launched):

```powershell
gradlew test
```

Perf/allocation tests print `[Perf]` lines through `System.out` by design.

## Short player overview

- Create a world with the **One Block** world type. A free generator can be claimed by right-clicking it.
- Break the block above the generator — it is replaced from the active set (blocks, mobs, fluids, chests, saplings).
- Coins (OBU) are earned by mining or selling (`/obuSell`, `/obuSellAll`); the mode is set in Settings → Manage Prices.
- Unlock and upgrade sets, meet unlock conditions, invite friends as generator members.
- Full mechanics are described in the in-game **Guide Book**.
